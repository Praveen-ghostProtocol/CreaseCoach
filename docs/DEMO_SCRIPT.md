# Classroom demo · 4–6 minutes

Open the production app on the presentation laptop once with internet access so the short demo clips can be cached. Use [Load comparison demo](https://praveen-ghostprotocol.github.io/CreaseCoach/?demo=1#video-demo) to open the two prepared clips at Downswing. This link also works offline after the production cache is ready. A rehearsal in the same browser profile confirms that both videos are available.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:40 | Home and fictional player | A developing batter wants to know what to try in the next nets session. Point out the six recorded innings and one next step. |
| 0:40–1:25 | Performance Log | Add a caught dismissal or edit an existing one. Enter only the known fields and leave a shot detail unrecorded. |
| 1:25–2:10 | Performance Insights | Show the new counts, denominator and drill-down. Read the observation and hypothesis separately. |
| 2:10–2:55 | Side-by-side Video Lab | Open the one-click comparison and select **Projection view**. The two attempts show the same batter and camera position. Play both at half speed, switch from Downswing to Follow-through, and return to the marker. |
| 2:55–3:45 | Batting timeline and anthropometry | Select **Review frame** for Clip A at Downswing. Record a timestamped observation and enable **Use in practice plan**. Show that the practice batter’s body dimensions are unrecorded, then introduce the published NHANES example. |
| 3:45–5:00 | Next Session Plan | Select **Build a practice plan**. Edit and save one objective. Under **Evidence when saved**, open the clip link and show that it goes to the exact frame. |
| 5:00–5:30 | Evaluation | Show how the app supports recall and decision-making. Describe the unstructured notes comparison and state that the participant study is planned. |

For the expected initial pattern, use the calculation **3 of 5 recorded dismissals were caught**. Keep the walkthrough on the fictional or schematic workspace unless you have a clip cleared for the demonstration.
